# # 🚀 Catálogo Express - Landing Page para Comercios Locales

Plantilla web minimalista, moderna y ultrarrápida diseñada para pequeños comercios, tiendas de ropa y emprendedores locales que necesitan mostrar su catálogo y conectar directamente las ventas con **WhatsApp**.

---

## ✨ Características
* **Diseño Responsivo (Mobile-First):** Optimizado para verse perfecto en celulares, tablets y computadoras.
* **Integración Directa con WhatsApp:** Botones personalizados por producto con mensajes automáticos listos para que el cliente pregunte por la compra.
* **Estilo Oscuro Moderno (Dark Mode):** Estética limpia y actual con tipografías claras.
* **Sin Dependencias Pesadas:** Hecho con HTML5 y CSS3 puro (sin frameworks lentos), lo que garantiza una velocidad de carga inmediata.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5** (Estructura semántica)
* **CSS3** (Grid Layout, Flexbox y Variables CSS)
* **GitHub Pages** (Alojamiento web gratuito y seguro)
